用途

Hermes Desktop 係 Chun Hin Ng 自用嘅私人 AI 助理，唔對外提供服務。

會存取嘅資料

經 Google OAuth 授權後，可能會讀取本人 Google 帳戶嘅 Gmail、日曆、雲端硬碟、文件、試算表同聯絡人，只用嚟為本人整理提醒、摘要同處理本人要求嘅工作。

資料點處理

  • 資料只喺本人控制嘅伺服器處理同儲存。
  • 唔會出售、出租或者分享畀任何第三方。
  • 唔會用嚟賣廣告。
  • Google 用戶資料嘅使用遵守 Google API Services User Data Policy（包括 Limited Use 規定）。

撤銷授權

可以隨時喺 Google 帳戶權限頁 移除 Hermes Desktop 嘅存取權。

English summary

Hermes Desktop is a private, single-user AI assistant operated by Chun Hin Ng. Google user data is accessed only to serve the owner's own requests, is processed on the owner's own server, is never sold or shared with third parties, and is used in accordance with the Google API Services User Data Policy, including the Limited Use requirements.
